Perfusion Sentinel v1.14.0 — final v1 research snapshot

Frozen commit: ace6a9fed2f9084b5fda95e9e1113af7a3d93dca
Python: 3.10 or 3.12. Free packages only; no hardware or paid data.

Verify downloads: sha256sum -c SHA256SUMS
Unzip perfusion-sentinel-v1.14.0-source.zip and enter its directory.
Verify source: sha256sum -c SHA256SUMS
Create a fresh virtual environment and install:
  python -m venv .venv
  . .venv/bin/activate
  python -m pip install -e ".[audit]"
  python -m unittest discover -s tests -v
  python examples/validate_model_bank_study.py
  python examples/build_model_bank_web.py --check
  python examples/check_versions.py
  node tests/web_contract.cjs
Full historical validation commands are in .github/workflows/ci.yml.

To rerun the complete v1.14 study (overwrites generated results):
  python examples/model_bank_study.py --stage develop
  python examples/model_bank_study.py --stage evaluate
Both stages must use this frozen source. Selection is development-only.

The wheel installs Python runtime modules and the original CLI; the full source
ZIP is required for frozen datasets, study scripts, validators and web replays.
example-config.json records the original CLI smoke-run values. Equivalent run:
  perfusion-lab run --scenario compound --policy sentinel --seed 100 --duration 1200 --dt 2 --target 280 --out smoke
It does not select the v1.14 model-bank controller; that study uses its dedicated
script and retained results/model-bank-study/selection.json.

The model-bank hybrid has conditional gains, but the complete PI comparison and
v2 evidence gates fail. Biased/shared calibration can cause depletion and empty
requests. All failures are preserved. No clinical, hardware, novelty or general
controller-superiority claim is established. No paper drafts are included.
